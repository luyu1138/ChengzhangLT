# 成长蓝图 · Android 1.1.1

按照 [V1.0 产品设计](docs/产品设计-V1.0.md)实现的个人与家庭成长管理应用。首版提供多人档案、目标规划、行动与习惯、成果记录、周期复盘和加密备份。本次按用户新要求增加天空蓝界面、每人固定计划与到时提醒、完成历史，以及每日上传阿里云 OSS 的加密备份。未配置 OSS 时离线运行；只有用户在 App 内录入自己的配置并启用后才上传。阿里云盘接入不再作为这一版的备份方案。

**验证状态：** 本版 39 项领域、13 项浏览器、25 项 JVM 原生逻辑、2 项加密互操作检查通过，合计 79 项。1.1.0 的 10 项 Android 平台通过及 2 项 WebView 引擎失败为历史结果，当前补丁未重跑平台用例；完整 APK 界面与真实 OSS 联调尚未验收。详见 [交付记录](docs/交付与测试.md)。

## 安装

下载本地签名试用包 [成长蓝图-v1.1.1.apk](releases/成长蓝图-v1.1.1.apk)，在 Android 系统中允许安装该来源的应用后打开。最低 Android 8.0（API 26），需要 Android System WebView / Chrome 110 或更新版本。APK 支持各 CPU 架构，本地功能无网络运行依赖；OSS 备份使用网络权限，固定计划可选申请准时提醒权限。不申请通讯录、定位或通用文件存储权限。

这是使用独立本地签名证书打包的可安装 release 版本，未上传应用商店。证书摘要和 APK 校验值见 [交付说明](docs/交付与测试.md)及 [SHA256SUMS](releases/SHA256SUMS)。私钥和口令保存在构建环境的 `/workspace/.tools/signing/`，不进入 Git；后续覆盖安装必须使用同一证书。正式渠道发布应接入产品方保管的签名密钥。

## 本地功能

- **多人首页**：独立人物 ID、昵称/关系/时区/关注点、搜索、置顶与排序、年度进度、今日行动、近期记录、复盘提示；档案归档、回收站、恢复及彻底删除。
- **规划**：长期、年度、季度及近期目标；同人物父子关联、防循环与周期约束；增长、降低、里程碑、频次和五级量表；权重与覆盖率、时间预算、基础/挑战目标、草稿激活、人工验收、暂停与终止。
- **可追溯调整**：调整原因、前后影响预览、目标版本及历史；年度统计范围显式修订，暂停与终止不自动移除目标。
- **行动**：一次性任务、每日、每周指定星期、每周 N 次、每月指定日和间隔习惯；幂等完成、撤销、保留原计划的改期、习惯暂停、按人物或全部人物查看。
- **记录**：成果与行动分开计量；最新状态或累计增量、补录、同一观察时点冲突确认；PNG/JPEG/PDF 证据附件。单文件 ≤5MB，全部附件 ≤10MB；文件类型、归属和摘要校验。
- **复盘**：周/月/季/年复盘，草稿与发布、冻结快照与修订、下周期重点转行动；Markdown、CSV 明文导出及 Android 打印/PDF 阅读版。
- **安全**：Android Keystore、AES-256-GCM 加密 SQLite 载荷，业务快照与 outbox 在同一事务写入；关闭系统备份，可开启截图保护；逐人物固定计划通知、可选准时提醒权限及额外通用每日提醒。
- **备份**：独立 256 位随机恢复码、认证加密导出、错误密钥/密文/新格式拒绝、附件 SHA-256 校验、预览后显式切换空间。

首次启动没有演示人物或虚构进度。添加家人档案需确认有记录与管理授权。复盘中的数字不会因后续补录和目标调整而改变。没有有效指标时显示待补充，部分指标缺失时单独展示已知进度与覆盖率。

## 1.1.1 OSS 排错修复

OSS 请求失败时显示上传/下载阶段、具体错误码及有效请求编号；不展示原始服务端错误内容中的密钥或签名。失败后不再残留“等待首次备份”或保存成功说明。403 的根因需结合实际错误码、RAM 授权、Bucket 配置等确认，详见 [检查步骤](docs/OSS接入与使用.md)。

## 固定计划与 OSS 备份

- **天空蓝界面**：蓝色按钮、浅蓝背景、导航、状态栏与启动图标统一。
- **个人固定计划**：在“行动 → 添加固定计划”选择每日、每周指定星期或每月指定日，设置人物时区中的提醒时间；短月没有指定日则跳过。
- **完成记录**：勾选到期行动后记录计划日期和实际完成时间，在“完成记录”按月查看；撤销仍保留修订日志。暂停、归档、删除、完成与改期会重新计算提醒。
- **OSS 每日加密备份**：在“设置 → 阿里云 OSS”填写私有 Bucket、地域和专用 RAM 凭据，单独保存恢复码后启用。系统每天安排网络可用时上传并回读校验，首次启用和漏备后的启动会补试；支持立即备份、暂停、查看状态及移除本机配置。

OSS 配置详见 [接入与恢复步骤](docs/OSS接入与使用.md)。这是每日备份，不是双设备实时合并。每台设备每天一个文件，同日重试/手动备份会覆盖当天文件；以前日期的文件保留并计费，需要在 OSS 控制台配置生命周期。Android 省电、关机和强制停止会影响执行时间，不能保证恰好每 24 小时或某个时刻完成。

## 开发与构建

界面采用 React 19 + TypeScript + Vite；Android Java 外壳负责受限 WebView、系统安全密钥、加密 SQLite、系统文件选择/保存、通知和 PDF。采用这一 Android 优先实现以交付离线 APK；没有采用设计中建议但非强制的 Flutter，当前不包含 iOS 工程。Android 的 JobScheduler、AlarmManager 和原生 HTTPS 负责独立于 WebView 的后台备份与提醒。

需要 Node 22+、Python 3.12+、JDK 21、Android SDK 35 / Build Tools 35.0.0。Linux 云环境的初始化命令：

```bash
cd /workspace/ChengzhangLT
python3 scripts/setup-cloud.py
source scripts/cloud-env.sh
npm ci --cache /workspace/.tools/npm-cache
npm test
npm run android:debug
```

已有本机 Android SDK 时设置 `JAVA_HOME`、`ANDROID_HOME`，使用 `android/gradlew` 即可。Gradle wrapper 固定 8.13 并校验官方 SHA-256。初始化脚本保留 TLS 和下载校验，Java 下载器使用当前环境的代理与受信证书。

```bash
npm run dev               # 浏览器开发；浏览器存储使用 WebCrypto 加密 IndexedDB
npm run build             # TypeScript 检查与离线资源构建
npm test                  # 领域和备份测试
npm run test:e2e           # UI 自动化；默认 /usr/bin/chromium，可设置 CHROMIUM_PATH
npm run test:native        # JVM 原生规则、官方 OSS SDK 签名比对、HTTP 传输及恢复互操作
npm run android:test       # 已启动的专用 Android 模拟器上的平台测试（存储、后台备份、通知 + WebView）
npm run android:smoke      # 安装 debug APK，验证界面和强制重启持久化；仅用于空白测试模拟器
npm run android:release    # 构建并签名 release APK，输出到 releases/
```

`android:test` 会清空测试安装的数据库，`android:smoke` 会清空专用模拟器中的本应用数据；勿在有真实数据的设备上运行。Android 实机签名通过环境变量 `BLUEPRINT_KEYSTORE`、`BLUEPRINT_STORE_PASSWORD`、`BLUEPRINT_KEY_ALIAS`、`BLUEPRINT_KEY_PASSWORD` 注入，不将私钥或口令写入源码。

每个云任务已经隔离，使用现有 checkout，无需建立额外 Git worktree。编译结果、SDK 与签名材料为保留文件；模拟器、开发服务器、adb 等进程需在新任务中重新启动。

## 使用与数据边界

OSS 每日备份与手动加密备份分别使用自己的恢复码；凭据与 OSS 恢复码仅加密存放在当前设备，不打包进业务备份。没有跨设备自动下载/合并。恢复时会替换当前空间，不静默合并，请先备份当前空间。恢复码丢失无法由运营方找回；卸载应用会丢失本机数据与设备密钥。

彻底删除只覆盖当前应用管理的本机实体、附件和日志；已导出或复制的文件需要自行清理。应用层删除不承诺对存储介质残留进行取证级抹除。

设计中的完整云协议、设备撤销/密钥轮换、云快照保留、真实双设备故障注入，以及 50 人物/10 万记录的中端机性能验收，均不在本地版已验证能力中。具体交付范围与未验收项见 [交付与测试](docs/交付与测试.md)。
