# 成长蓝图 1.1.1：OSS 403 排查修正版

日期：2026-10-21。用户报告保存 OSS 配置后出现 HTTP 403。截图能够证明配置已保存，失败发生在 OSS 请求阶段；1.1.0 把不同 OSS 错误统一显示为泛化文案，无法从截图确定是权限、密钥、地域、签名或其他访问限制。本版改进错误诊断与状态显示，不声称已查明或解决用户账户的真实 403。

## 修改

- 原生请求失败时，区分上传 PUT 与上传后的下载校验 GET，显示 OSS 返回的已识别错误码、有效请求编号及对应操作建议。
- AccessDenied 分别提示 `oss:PutObject` / `oss:GetObject`；密钥无效、签名不匹配、签名地域错误、时间偏差、账号异常等使用不同提示。
- 不显示或持久化原始错误 XML、Message、StringToSign、签名、密钥或恢复码。响应只读取最多 64KB；只提取白名单 Code 和经过格式校验/敏感值过滤的 RequestId，不解析 XML 实体。
- 读取失败或未知响应仍保留 HTTP 状态；不跟随重定向发送凭据。上传/回读验证逻辑未放宽，失败不会更新成功标记。
- OSS 已失败时状态显示“最近备份失败 · 等待重试”，不再显示“等待首次备份”或残留的配置保存成功说明。错误文案支持换行与大字号。
