# 成长蓝图 1.1.2：自动备份开关与手动成功提示

日期：2026-10-21。本版按用户要求调整 OSS 操作界面，自动备份与手动备份分别控制；后续发布仅递增版本末位。

## 修改与使用

- 页面上方使用“每日自动备份”开关，切换后立即加密保存；关闭会取消每日任务及自动补试，保留云端文件和手动任务。
- “保存 OSS 配置”单独保存 Bucket、地域与凭据。首次配置默认关闭自动备份，后续保存保留原开关；旧版启用状态直接兼容，不需要重填密钥或恢复码。
- 保留独立“立即备份”按钮，自动开关关闭时也可使用。排队请求去重，网络等待、上传校验、失败分别显示；原生手动任务有持久化请求编号，自动备份的成功时间不会触发手动成功。
- PUT 后下载完整密文并校验 SHA-256，一致后才记录本次手动成功和时间。界面显示绿色大号“立即备份成功”卡片，并自动滚动/聚焦以便看到；新请求会清除旧成功提示，校验失败保留上一份成功记录而本次显示失败。
- 关闭自动备份不会中止进行中的手动上传；移除/替换配置会使旧任务失效，不能回写旧成功状态。系统拒绝安排自动任务时回退开关，显示错误。
- 版本从 `1.1.1` 更新为 `1.1.2`，Android versionCode 从 3 增至 4。[AGENTS.md](../AGENTS.md)记录以后仅递增最后一位的发布要求。

[界面示例](screenshots/oss-v1.1.2-success.png)来自 Chromium UI 测试的明确原生桥替身、虚构 Bucket 与时间，用于说明外观，不是用户账户的真实云端成功凭证。

## 验证边界

本环境没有真实 OSS 凭据，未执行用户账户上传/下载或修改 RAM/Bucket 权限。用户此前 HTTP 403 的真实根因仍需结合手机显示的错误码核对；本版保留 1.1.1 的错误诊断，不声称已解决账户权限。接入、费用、恢复与排错见 [OSS 使用说明](OSS接入与使用.md)。

完整 APK 页面、强制重启、真实账户、跨日调度与换机恢复尚未完成端到端验收。云主机缺少 KVM，1.1.0 的两项独立 WebView 引擎测试曾发生 renderer-crashed；本次没有重复这些已知环境失败，18 项平台检查不包含 WebView 引擎测试，不能等同于完整真机验收。
