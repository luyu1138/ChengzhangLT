## 数据与安全实现

Android SQLite 中只保存经过 AES-256-GCM 认证加密的业务快照及日志载荷；可见的元信息为随机操作 ID、序号与数据库结构。密钥由 Android Keystore 生成和保护，随机 nonce 不重用；快照及 outbox 使用不同认证上下文。没有把密钥放入 APK，也没有使用短 PIN 作为内容密钥。

备份使用独立 32 字节随机恢复码和 AES-256-GCM；恢复码不进入备份文件。恢复先在内存中验证格式、人物关系、数据范围和附件 SHA-256，预览并确认后才提交当前空间。Android 原生事务验证失败时不保存成功提示。

应用关闭系统自动备份、明文 HTTP 和文件 URL 访问；WebView 只加载打包的 `https://appassets.androidplatform.net/` 资源，拦截其他请求。release 关闭 WebView 远程调试。应用不申请 INTERNET 权限；云盘入口明确未开放。PNG/JPEG/PDF 不执行脚本，导出使用系统文件保存器。CSV 导出转义公式前缀与引号。

## 当前安卓运行验证阻塞

`WebViewStartupTest` 使用独立的微型 HTML，不加载 React、业务脚本、数据库或云端接口。两个用例（基础 JavaScript、本地 HTTPS 拦截与安全随机数）都捕获了系统 WebView 渲染进程退出。原始失败结果见 `docs/testing/android-webview.xml`。应用已增加渲染进程退出后的恢复页面，并将密钥/数据库初始化移出 Activity 主线程；没有关闭失败断言，也没有把相关用例记为跳过。

当前 APK 为供进一步验证的本地签名试用包。下一步需要在具备 KVM 等硬件加速的 Android 模拟器或真实安卓设备上继续完成安装、多人档案/行动/备份和强制重启验证。当前云机器内可继续开发、构建、运行浏览器与原生存储测试，但完整 Android 界面运行尚未就绪。

## 尚未完成的设计项

阿里云盘 OAuth/PKCE、获批场景、同步协议、双设备冲突、云快照/恢复和删除保留策略，需要应用准入后开发和实测。未以手动导出替代云盘自动同步。

本地版还有明确边界：当前快照式加密载荷适合个人与家庭常规数据量，尚未完成 50 人物/10 万记录的目标规模性能验收；不能据此声称达到设计中的 P95 性能值。附件总量 10MB、单个 5MB、备份文件 20MB，是此版本的实现限制。数据量增大时应迁移为分实体加密存储与增量聚合。

暂未提供习惯规则修改界面、照片头像、月周可视排程、趋势图、自定义长期复盘、应用 PIN/生物识别解锁、提醒主设备管理。当前复盘支持周/月/季/年，头像以首字代替。不支持跨账号协作、iOS 和后台云同步。

发布应用商店前还需产品方签名、渠道材料、隐私政策、真机无障碍/性能/通知与系统文件保存器测试；本次不宣称完成商店审核或设计全部上线门槛。
